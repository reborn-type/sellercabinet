# Кабинет продавца

React + TypeScript + Vite. Интерфейс работает с API существующего gateway.

## Запуск

Требуется Node.js 22 LTS версии 22.12 или выше.

```bash
cd frontend
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. Gateway должен быть доступен на http://localhost:8085.
Запросы /api проксируются Vite в gateway, который маршрутизирует их в сервисы.

Для другого адреса скопируйте .env.example в .env.local и задайте API_PROXY_TARGET.
VITE_API_BASE_URL определяет адрес API в браузере, по умолчанию /api.
Параметры VITE_* публичны и попадают в клиентскую сборку.

## Проверки и сборка

```bash
npm test
npm run build
npm run preview
```

Сборка создаётся в dist/. Preview также проксирует /api в gateway.
Для публикации dist/ сервер должен возвращать index.html для маршрутов интерфейса и проксировать /api в gateway.
Можно задать полный публичный адрес gateway через VITE_API_BASE_URL перед сборкой.

## Структура

- src/api — типизированный HTTP-клиент, JWT-сессия, единичный refresh при параллельных 401, нормализация ошибок и DTO.
- src/auth — контекст текущей сессии.
- src/components/ui — кнопки, поля, модальные окна, сообщения и карточки показателей.
- src/components/products — карточка, форма и подтверждение удаления товара.
- src/components/analytics — показатели и таблица статистики.
- src/pages — вход, регистрация, товары и аналитика.

## Поведение

После регистрации пользователь автоматически входит в кабинет.
Сессия хранится в sessionStorage текущей вкладки. Пароль не сохраняется.
Клиент обновляет access-токен через /api/auth/refresh и очищает сессию при отказе обновления.

Продавец видит свои товары и статистику. Доступны создание, изменение и удаление товара.
Администратор видит все товары, фильтр по ID продавца и общую таблицу аналитики.
Права на операции проверяются сервером.

Аналитика формируется асинхронно. Для получения новых показателей есть кнопка «Обновить».
Интерфейс содержит состояния загрузки, отсутствия данных, ошибок и валидации.
