# Кабинет продавца маркетплейса 

Этот репозиторий содержит учебный проект нацеленный на создание кабинета продавца маркетплейса, 
который проводит ABC анализ на высокомаржинальные товары, а также предоставляет сводную информацию по товарам продавца, 
это упрощает дальнейшее планирование закупок для малых индивидуальных предпринимателей.


## Основной функционал


### Продавец

При создании аккаунта продавец вводит следующие данные:
* Имя (от 2 до 50 символов)
* Фамилия (от 2 до 50 символов)
* Возраст (от 18 до 110)
* Электронная почта (от 5 до 50 символов)

Продавец создает аккаунт и получает доступ к созданию товаров с имеющейся информацией: 

* Название товара
* Стоимость товара (за 1 ед.)
* Количество товара в наличии (шт.)
* Количество проданного товара (шт.)
* Средняя оценка товара (от 1.00 до 5.00)

Все данные вводятся вручную продавцом и берутся за период в 30 дней. 

### Получение информации по товарам

После создании товара, продавец может провести ABC-анализ: 
* ABC-анализ классифицирует объекты по их вкладу в общий результат
  * A - товары с накопительным итогом до 80%
  * B - товары с накопительным итогом от 80% до 95%
  * C - товары с накопительным итогом от 95% до 100%
По итогу анализа продавец получает наиболее выгодные товары, где 20% товаров формируют 80% выручки.

Также продавец может получить сводную статистику по своим товарам: 
* Общее количество продаж всех товаров
* Суммарный заработок с продаж конкретного товара
* Предполагаемая стоимость товаров на складе

## Развертывание 

* Для того чтобы запустить backend + db + javaFX, Вам необходимо иметь docker на персональном компьютере
* Клонировать репозиторий и перейти в папку проекта
* Скопировать `.env.example` в `.env` и заполнить его своими настройками
  * Чтобы скопировать `.env.example` можно воспользоваться командой `cp .env.example .env`
* Запустить `docker compose up --build`
* Запустить приложение `sellercabinet.exe`
В случае если Вы собираетесь использовать консольную версию сервиса, после `docker compose up --build` используйте команду `docker compose run --rm --service-ports app`
